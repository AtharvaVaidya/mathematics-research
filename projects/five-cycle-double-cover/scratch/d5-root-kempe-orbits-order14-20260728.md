## Claim tested

Let \(G\) be a connected bridgeless simple cubic graph, let
\(q:E(G)\to\binom{[5]}2\) satisfy the xor-zero equation at every vertex,
and let \(r,s\) be two distinct edges.  For \(i<j\), put
\[
 Y_{ij}=\{e:|q(e)\cap\{i,j\}|=1\}.
\]
A Kempe move transposes \(i,j\) on one circuit component of \(Y_{ij}\).
The audit tests:

> In every Kempe orbit of \(D_5\)-flows, every unordered root pair
> \(r,s\) can be placed on one component of some \(Y_{ij}\).

This conditional orbit statement would be useful in an inductive FiveCDC
argument.  A finite positive census does not prove it universally.

generates 480 nonisomorphic biconnected simple cubic graphs of order 14.
The exact C++ audit obtained:

| quantity | count |
|---|---:|

| Kempe orbits modulo global \(S_5\) | 33,102 |
| orbit/root-pair tests | 6,951,420 |
| failing orbits | **0** |

There are \(\binom{21}{2}=210\) unordered root pairs per orbit, so
\[
             33\,102\cdot210=6\,951\,420.
\]

The producer:

1. decodes each graph6 record;
2. enumerates every weight-two edge labeling satisfying the local xor
   equations, quotienting only by a global permutation of the five
   coordinates;
3. constructs the complete state graph generated by componentwise Kempe
   transpositions; and
4. unions all root pairs lying on a common \(Y_{ij}\)-component over each
   orbit.

The machine-readable output has one JSON object per graph followed by an
arithmetic summary:

## What remains open

The finite result pushes the exact orbit-level boundary through order 14.
It does not prove that an arbitrary Kempe orbit has the rooted
common-circuit property, and therefore does not resolve FiveCDC.

A tempting direct proof by strict ascent of
\[
 P(q;r,s)=\max\{|C|: C\text{ is a }Y_{ij}\text{-component containing }r\}
\]
is already false on the cube: a root-bad state with \(P=8\) has no
one-move neighbour that is root-good or has larger \(P\).  It is rescued
by moving across an equal-\(P\) plateau and then making a second switch.
Thus a valid structural proof needs a secondary potential or a
multi-switch component-incidence argument.
